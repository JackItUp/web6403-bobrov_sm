# Лабораторная работа №4

«Безумный магазин» — модернизация сайта из лабораторной работы №2.

- `index.html` — главная страница: Flexbox для навигации и покачивание заголовка с помощью CSS.
- `catalog.html` — каталог товаров: Grid: две колонки товаров на широком экране, одна на узком.
- `about.html` — информация о магазине и таблица цен.
- `login.html` — учебная форма авторизации: text, email, password, checkbox.
- `style.css` — CSS-переменные для всех цветов, анимация заголовков и классы по БЭМ.
- `script.js` — класс `User` с конструктором и методом `printInfo()`.

Чтобы проверить: откройте `login.html`, заполните форму и нажмите «Войти».
Результат выводится в консоль браузера (F12 → Console). Пароль отображается звёздочками.

**Важно:** авторизация демонстрационная; запросов на сервер и проверки учётных данных нет.
